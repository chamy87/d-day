Action button; use `primary` (amber) for the single main action per view, `secondary` for neutral actions, `ghost` for row-level actions, `danger` for destructive.

```jsx
<Button variant="primary" size="lg">Enter league</Button>
<Button variant="ghost" size="sm">Add to queue</Button>
```

Props: variant (primary|secondary|ghost|danger), size (sm|md|lg), disabled, icon (leading node).
